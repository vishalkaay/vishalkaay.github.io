FPGA · CS666 · 2025

Pipelined AES-128 Core

An 11-stage pipeline with parallel key expansion, verified against NIST vectors and running on a PYNQ-Z2.

  • Verilog
  • Vivado
  • AXI4-Lite

A high-throughput AES-128 encryption core built for CS666, Hardware Security for IoT, under Prof. Urbi Chatterjee.

Highlights

  • 11-stage outer-round pipelined architecture: once the pipe is full, one 128-bit block comes out every clock cycle.
  • Key expansion runs in parallel with the cipher rounds, which removes the critical timing path and raises throughput.
  • Verified with standard NIST test vectors through simulation and waveform-level timing analysis.
  • Deployed on a PYNQ-Z2 (Zynq-7000 SoC) over AXI4-Lite, with full RTL, testbenches and Vivado project files.

GPU computing · IDC606 · 2026

2D Poisson Solver on GPU

Replaced iterative Red-Black SOR with a spectral FFT solver: 28.9 s down to 0.36 ms on a 1024×1024 grid.

  • CuPy
  • NVIDIA Warp
  • FFT
  • DLPack

A high-performance spectral solver for the 2D Poisson equation, built for IDC606 under Prof. Mahendra K. Verma on an NVIDIA RTX PRO 6000.

28.9 svectorised SOR baseline
0.36 msGPU spectral FFT
~10⁻¹⁶L2 error

How

  • Swapped the vectorised Red-Black SOR baseline for an O(N² log N) spectral FFT method, so there’s no iterative convergence to wait for.
  • GPU-accelerated FFTs through CuPy, with custom kernels in NVIDIA Warp.
  • DLPack zero-copy interop keeps the whole data path on the GPU — no host round-trips.
  • Accuracy stays at machine precision (L2 ≈ 10⁻¹⁶) at an ~8,000× speedup.

Deep learning · CHE629 · 2026

Gene Expression with Dual Attention

A hierarchical BiLSTM that predicts whether a gene is on or off from histone marks. It matches a CNN with 11× fewer parameters, and its attention rediscovers known epigenetic rules on its own.

  • BiLSTM
  • Attention
  • Focal loss
  • Genomics

Predicting binary gene expression from 5 histone modification marks across 100 bins spanning ±5 kb around the transcription start site, on 19,799 genes from the REMC E003 embryonic stem cell dataset. Built for CHE629 under Prof. Sana Khanum.

0.788test AUC
59Kparams vs 644K (CNN)
5×minority-class F1

Approach

  • Benchmarked a CNN against a hierarchical BiLSTM with two attention layers: bin-level spatial attention and mark-level combinatorial attention.
  • Handled heavy class imbalance (79.2% inactive) with focal loss, LR scheduling on validation AUC, gradient clipping and early stopping.
  • Approaches the published DeepChrome and AttentiveChrome baselines.
  • Without any annotation, the learned attention focuses on the TSS, keys on H3K4me3 for active genes and H3K27me3 for repressed ones.

GIFSleuth

A zero-dependency GIF forensics engine that finds polyglots, web shells, appended archives and stego payloads.

  • Python
  • Forensics
  • CI

A GIF security scanner that parses GIF87a/89a byte streams itself and runs seven detectors on the regions a renderer never draws.

7detectors
19file signatures
143unit tests
  • Detects GIFAR, trailer-appended payloads, content-sniffing XSS polyglots, embedded web shells and gifshuffle steganography.
  • Combines signature matching with Shannon entropy to flag encrypted or packed payloads, and reports their offsets.
  • Cuts false positives by scanning only renderer-ignored regions and stripping power-of-two palette padding from LZW data.
  • Self-registering plugin architecture; JSON, CSV and ANSI reports; contractual exit codes for CI.
  • GitHub Actions matrix across Python 3.11–3.13.

Go CLI · Open source · 2026

histwise

Reads your bash, zsh or fish history and suggests the aliases that would save you the most keystrokes.

  • Go
  • CLI
  • Offline

Everyone means to set up aliases and never does — and when they do, they guess. histwise answers the question with your own data.

  • Parses bash, zsh and fish history formats and shows what you actually type most.
  • Ranks alias candidates by (command_length − alias_length) × times_used: real keystrokes saved, not raw counts.
  • Ships as a single static binary. Fully offline, never phones home, never modifies your history.
  • histwise --aliases >> ~/.bash_aliases and you’re done.
